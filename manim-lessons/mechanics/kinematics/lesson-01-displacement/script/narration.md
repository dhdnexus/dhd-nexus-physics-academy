# Narration / Presenter Guide — Displacement

Paired with `storyboard.md`. Each entry: what to say, when to pause,
what to ask, and what misconception to anticipate.

## 1. Reference Frame
Say: "Before we can talk about motion, we need to agree on where
zero is, and which way is positive." Point at the origin, then the
positive-direction arrow. Pause after drawing the frame — ask
students to state the units out loud.

## 2. Position
Say: "This vector, r, always starts at the origin. It tells you
where the object is right now — nothing more." Anticipate: students
conflating "position" with "displacement" — explicitly name the
difference before moving on (misconception:
`position-is-displacement`).

## 3. Displacement
Say: "Now watch what happens when the object moves from here to
here." Draw the displacement vector directly from r_i to r_f. Ask:
"Does this vector care what path was taken to get there?" Pause for
an answer before continuing — the answer is no.

## 4. Distance vs Displacement (detour)
Say: "Let's send the object on a detour." Let students watch the
distance counter grow while the displacement vector doesn't change.
Ask: "Why isn't the displacement vector updating even though the
object is still moving?"

## 5. Return to Origin
Say: "This is the case that trips almost everyone up." Let the object
return to its start. Pause on the final frame — displacement is
zero, distance is not. Ask: "If displacement is zero, did the object
do any work moving? What does zero displacement actually tell you?"
Anticipate misconception: `displacement-is-distance`.

## 6. Position–Time Correspondence
Say: "Watch the dot on the graph as the object moves on the number
line — they're the same motion, just two views of it." If students
seem to be reading the graph as a picture of the path, stop and
clarify: "This is position versus time, not a map."

## 7. Equation Recap
Say: "One equation for displacement, one idea for distance." Refer
students to the lecture note for the full derivation and worked
examples, and to the Web Lab to try the three routes themselves.
Transition: "Now go try this yourself in the Academy — change the
initial and final position and watch what stays the same and what
doesn't."
