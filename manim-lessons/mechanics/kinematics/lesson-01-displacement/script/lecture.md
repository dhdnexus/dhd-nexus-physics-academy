# Learning Objectives

By the end of this lesson, students should be able to:

1. Define position.
2. Define distance.
3. Define displacement.
4. Distinguish between distance and displacement.
5. Determine displacement using a coordinate system.
6. Calculate displacement in one dimension.
7. State the SI unit of displacement.
8. Recognize displacement as a vector quantity.

# Common Misconceptions

Distance equals displacement.

Displacement is always positive.

Returning to the starting point increases displacement.

Displacement depends on the path taken.
