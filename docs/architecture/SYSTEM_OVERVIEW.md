# DHD Nexus System Overview v1.0

---

# Platform Overview

DHD Nexus is an integrated educational platform for undergraduate STEM education.

The platform is centred around a single concept:

> Create once. Deliver everywhere.

Every lesson is created one time and reused across multiple educational products.
